# PRD：旧页与续写会话（History, Relive & Continue）

**产品：** 墨语 · inkara  
**文档编号：** PRD-03  
**日期：** 2026-09-24  
**状态：** Accepted（经 grilling 定稿）  
**设计原则对齐：** `.impeccable.md`（控件按需；面板保持淡墨，不做仪表盘）

---

## 1. Summary

强化本地旧页的可寻与可重现，并定义答完后的会话节奏：**继续写**（上轮回复上移淡出作背景，保持记忆续问）与情境化的 **清页 / 新篇章**（同一按钮）。墨迹召回与列表「记忆重现」共用规则；多页命中时在纸上选出一页。记忆实现软顶 5000 页，产品不刻意强调上限。

## 3. Background

### 原有能力

| 能力 | 状态 |
|------|------|
| IndexedDB 记忆，硬顶 40，上下文约 8 页 | 已有 |
| 回顾面板：日历筛选、遗忘、清空 | 已有 |
| 墨迹召回 + `animateRecallPage` | 已有（单页最优匹配） |
| 答完后底栏：清页、导出 | 已有（`pageToolsVisible`） |
| 列表搜索 / 记忆重现 / 继续写会话模型 | **缺失** |
| 召回多匹配 | **缺失**（只取最高分一条） |

### 为什么现在做

有记忆不好用；答完后缺少「接着问」与「开新篇」的清晰节奏；「找 xxx」多命中时用户无选择权。

### Grill 结论摘要

本 PRD 从「旧页增强」扩大为 **旧页 + 全站续写会话**；PRD-02 语气已取消，不阻塞本项。

## 4. Objective

**目标：**

1. 10 秒内能搜到并「记忆重现」某次问答；  
2. 答完后能明确选择继续问或开新篇；  
3. 墨迹多命中时可在纸上点选，不卡死。

### Key Results

| KR | 指标 | 目标 |
|----|------|------|
| KR1 | 旧页关键词 ∩ 日历过滤 | 可用 |
| KR2 | 列表「记忆重现」与墨迹单页召回视觉一致 | 复用 `animateRecallPage`（含 reduced-motion） |
| KR3 | 多匹配时纸上候选 3～5 条可选 | 可用 |
| KR4 | 答完后：继续写 + 情境清页/新篇章 + 导出 | 按状态机验收 |
| KR5 | 记忆软顶 | 5000；触顶丢最旧 |
| KR6 | 无卡片仪表盘 / 无云同步 | 验收 |

## 7. Solution

### 7.1 决策锁定（Grill）

| # | 决策 | 选择 |
|---|------|------|
| Q1 | MVP 范围 | 搜索 + 记忆重现 + miss 文案 + **续写会话** + 软顶 |
| Q2 | 列表触发 | 每条独立操作「记忆重现」（非整条点击） |
| Q3 | 重现视觉 | `animateRecallPage`；reduced-motion 静置 |
| Q4 | 搜索 | 有记忆时标题下常驻 |
| Q5 | 上限 | 软顶 **5000**，触顶丢最旧；不对外主打限额 |
| Q8 | 文案 | 见 §7.4 |
| Q9/Q10 | 多匹配 | 纸上 3～5 候选 → 点选；空白/「算了」回今天 |
| Q11 | 清页与新篇章 | **同一按钮**，按状态换文案（§7.3） |
| Q16 | 继续写 | 答完后**独立按钮**；点后上移+淡出再可写 |
| Q17 | 新篇章 | 清视觉 + **断会话上下文**；IDB 旧页库保留 |
| Q18 | 导出 | 答完底栏保留 |
| Q19 | 多选取消 | 轻触空白或「算了」 |
| Q20 | 重现后 | **可直接写**（A2），视为已有对话背景 |

### 7.2 旧页面板

1. 有记忆时，标题下极简搜索框；placeholder 见文案表。  
2. 过滤 = 日历日 ∩ 关键词（transcription ∪ reply；大小写不敏感；中文子串）。  
3. 每条：操作 **记忆重现**、**遗忘**（整条点击不触发重现，防误触）。  
4. 无匹配 / 无记忆：明确空态。

**记忆重现：** 关面板 → 走与墨迹单页召回相同的 `animateRecallPage` → 结束后可直接书写（对话背景在）。

### 7.3 答完后底栏状态机

**出现时机：** 与现 `pageToolsVisible` 一致——普通回复完全浮现后显示；进入书写/清页/新篇章/提交 fading 时按规则隐藏。

**按钮组成：**

| 控件 | 何时可见 | 行为 |
|------|----------|------|
| **继续写** | 刚答完、尚未点继续写、且当前展示的是「本轮完整回复」（非已淡出背景态） | 当前回复**上移 + 淡出**作背景（不完全消失）→ 进入可写；本钮隐藏直至下一轮答完 |
| **清页 / 新篇章**（同一按钮） | 见下表 | 见下表 |
| **导出** | 与工具组同显隐 | 导出当前纸面 PNG（实现可保持现状） |

**清页 / 新篇章 情境表：**

| 条件 | 按钮文案 | 行为 |
|------|----------|------|
| 有笔迹或文字输入 | **清页** | 只清除当前输入（ink / typed）；若有「上次对话」淡墨背景则**保留**；再输入仍为续写语境 |
| 无输入，但有上次对话背景 | **新篇章** | 清空纸面视觉（含淡墨背景）；**断开会话上下文**（近期 prompt 不再带旧轮）；IndexedDB 旧页库**保留** |
| 无输入且无对话背景 | **不渲染该按钮** | — |

**「有上次对话背景」：** 存在未清除的上轮/重现淡墨回复层（continue 或 relive 之后）。

**回忆态（仅记忆重现、尚未开写）：** 可直接落笔；情境按钮按上表（通常无输入 + 有背景 → 显示「新篇章」）。不必先点「继续写」（Q20=A2）。  
**普通答完：** 须点「继续写」才上移淡出（Q16=A），避免误触落笔挤走新答。

### 7.4 墨迹召回

- 单页命中：同记忆重现；可直接续写。  
- **多页命中**（评分过线且前若干条接近）：不自动重现；纸上淡墨列出 **3～5** 条（日期 + 写下摘要一行）；点一条 → 重现；轻触空白或「算了」→ 回今天。  
- `recallMiss`：保留找不到文案，并提示可打开「旧页」查找（**不**自动打开面板）。

匹配算法可沿用 `findMemoryByQuery`，扩展为返回 top-N；阈值与「多候选」判定在实现 plan 中定（例如第二名分数 ≥ 某比例或 ≥ 绝对阈值）。

### 7.5 记忆存储

- 去掉硬顶 40；**软顶 5000**，`append` 时若超出则丢弃最旧。  
- `CONTEXT_PAGES`（近期注入 prompt 的条数）可另定，建议仍小（如 8），与软顶无关。  
- 「新篇章」不断开 IDB；「遗忘」/「清空回忆」才硬删。

### 7.6 文案定稿（i18n）

| Key 用途 | 中文 | English |
|----------|------|---------|
| 列表操作 | 记忆重现 | Relive |
| 搜索 placeholder | 搜索写下的字或纸答 | Search what you wrote or the reply |
| 继续写 | 继续写 | Continue |
| 清页 | 清页 | Clear |
| 新篇章 | 新篇章 | New chapter |
| 算了（多选取消） | 算了 | Never mind |
| miss 追加 | 也可打开「旧页」查找 | Or open Pages to look |
| 搜索无结果 | （新增）没有符合的旧页。 | No matching pages. |

### 7.7 User Stories & Acceptance Criteria

**Story A — 搜索**  
- [ ] 关键词 ∩ 日历；无结果空态；中英 placeholder  

**Story B — 记忆重现**  
- [ ] 列表点「记忆重现」→ 关面板 → 动画/静置 → 可写；不新写一条 memory  
- [ ] 轻触「新篇章」可清背景并断上下文  

**Story C — 继续写**  
- [ ] 答完后点「继续写」→ 上移淡出 → 可写；工具组按规则隐藏  
- [ ] 下一轮答完后工具组再出现  

**Story D — 清页 / 新篇章**  
- [ ] 有输入时为清页且保留对话背景  
- [ ] 无输入有背景时为新篇章且断上下文、保留 IDB  
- [ ] 空白无背景时不出现该按钮  

**Story E — 多匹配**  
- [ ] 多命中出 3～5 候选；点选重现；空白/算了回今天  

**Story F — 软顶**  
- [ ] 超过 5000 丢最旧；无云同步  

### 7.8 Non-Goals

- 云同步 / 多设备  
- 语义向量搜索  
- 多本日记  
- 回顾态专用「接着写」按钮（已由全站继续写 + 重现后可写覆盖）  
- PRD-02 语气微调  
- 把回顾做成双栏笔记编辑器  

### 7.9 Technology（示意）

- `src/lib/memory.ts`：软顶 5000；`getPageById`  
- `src/lib/recall.ts`：`findMemoriesByQuery` → top-N  
- `src/components/HistoryPanel.tsx`：搜索 + 记忆重现回调  
- `src/components/InkPage.tsx`：续写层、情境按钮、多候选 UI、与 `pageToolsVisible` 整合  
- `src/lib/i18n.ts` + `globals.css`：文案与上移淡出动效（尊重 reduced-motion）  

### 7.10 Assumptions

- 「继续写」的上移淡出足够表达上下文延续，无需聊天气泡。  
- 软顶 5000 对 IndexedDB 可接受；若实地膨胀再另案。

## 8. Release

| 阶段 | 范围 | 相对工期 |
|------|------|----------|
| **MVP** | 搜索、记忆重现、多匹配、继续写、清页/新篇章情境钮、导出保留、软顶 5000、miss 文案 | 约 3–5 天（大于原估，因会话模型） |
| v1.1 | 多匹配算法调参、动效微调 | 约 1 天 |
| 不做 | 云端分页、账号 |

**建议实现顺序：**

1. memory 软顶 + History 搜索 + 记忆重现接线  
2. 召回 top-N + 纸面候选  
3. 继续写动效 + 底栏状态机（清页/新篇章/导出）  
4. 手工验收全表  

**验收清单（手工，摘要）：**

1. 旧页搜索与日历交集正确  
2. 记忆重现后可写；新篇章后上下文断开但旧页仍在  
3. 答完 → 继续写 → 上移淡出 → 再答 → 工具再出现  
4. 清页 / 新篇章 三态切换正确  
5. 找宽泛词 → 多候选 → 点选 / 算了  
6. reduced-motion 下无长位移动画
