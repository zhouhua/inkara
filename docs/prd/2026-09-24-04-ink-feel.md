# PRD：书写与浮现手感（Ink Feel）

**产品：** 墨语 · inkara  
**文档编号：** PRD-04  
**日期：** 2026-09-24  
**状态：** Accepted（经 grilling 定稿）  
**设计原则对齐：** `.impeccable.md`（动效如电子墨水刷新；缓慢、线性、低闪烁）

---

## 1. Summary

墨语的差异化在「纸与墨」的身体感：笔迹、渗入、逐字浮现、底栏按需出现。当前体验已可用，但仍有抖动、节奏不稳、移动端安全区与键盘顶起、减弱动效路径不完整等问题。本 PRD 定义一轮**有界的体验打磨**（含压感曲线与高 DPI 一致性），不新增业务功能入口。

## 3. Background

### 现状

- 书写：Canvas + 压感线宽（`strokes`）；曲线偏简单  
- 渗墨：`fadeInkIntoPaper`（约 1.4s + blur）；reduced 已可即时清笔迹  
- 回答：手写体逐字浮现（非骨架笔顺；CJK 骨架已否决）  
- 底栏：PRD-03 后为会话 dock（继续写 / 清页·新篇章 / 导出）；已有部分 `safe-area-inset-bottom`  
- 键盘：未见 `visualViewport` 顶起处理  
- `prefersReducedMotion`：部分路径已覆盖，清单未清零；「继续写」上升淡出未统一约定  

### Grill 结论摘要

- MVP **含**压感精调与高 DPI/`dpr` 一致性（原 v1.1 部分提前）。  
- reduced 下回答：**整段淡入或直接出示**，不逐字。  
- **例外：**「继续写」rise/fade 在 reduced 下仍播完整动画。  
- **不冻结**后续手感微调；仍拒绝范围蠕变式「新动画种类」。

### 为什么现在做

功能面已够「能问能答」；手感决定品牌是否成立。适合在大功能之间插入一个专注质量的迭代。

---

## 4. Objective

**目标：** 在主流手机与桌面浏览器上，书写→提交→浮现的整段节奏稳定、不眩、不挡字；完整尊重减少动态偏好（续写动效除外见 §7.2）。

### Key Results

| KR | 指标 | 目标 |
|----|------|------|
| KR1 | 减少动态路径 | §7.2 审计清单清零（含标注的例外） |
| KR2 | 移动端 safe-area | 顶栏/底栏不被 Home Indicator 裁切 |
| KR3 | 文字模式键盘 | 聚焦时经 `visualViewport` 使提交提示仍可见 |
| KR4 | 浮现可读性 | 长回复不严重掉帧；流式与逐字不「卡住再蹦」 |
| KR5 | 无新功能入口 | 不增加与手感无关的设定开关（无「动画完整/减弱」覆盖项） |
| KR6 | 压感与锐度 | 有压感可感知粗细；高 DPI 下笔迹/回复不无故发虚 |

## 7. Solution

### 7.1 打磨范围（有界）

| 类别 | MVP 包含 | 明确不做 |
|------|----------|----------|
| A. 笔迹 | 双击误提交回归（保留双击，只修明显误触）；`strokeWidth` 压感曲线（死区、上限、无压感固定宽） | 笔毛、倾斜角、速度线宽、完整笔刷模型 |
| B. 渗墨 | 轻 blur 下调峰值；时长微调 ≤±200ms；reduced 即时清笔迹 | 粒子、水波纹 |
| C. 浮现 | 流式缓冲队列耦合；reduced 整段 ≤200ms 淡入或直接出示 | CJK 笔顺骨架、矢量描边动画 |
| D. 布局 | safe-area；`visualViewport` 垫高 dock；横屏基本可用 | 新纸张材质、暗色主题、横屏专项重排 |
| E. 控件显隐 | dock / 面板显隐与 reduced 一致（≤100ms opacity 或即时） | 新工具按钮 |
| F. 高 DPI | canvas 尺寸 / `dpr` / redraw 一致性审计与修复 | 锐化/对比滤镜 |

### 7.2 减少动态审计清单

`prefers-reduced-motion: reduce` 下：

- [ ] `fadeInkIntoPaper` → 即时清笔迹（已有则回归确认）  
- [ ] 回答浮现 → **整段淡入（≤200ms）或直接出示**，不逐字  
- [ ] `.submit-dock-tools` / 会话 dock 显隐 → 即时或 ≤100ms opacity  
- [ ] 设定/回顾面板开闭 → 即时或 ≤100ms opacity  
- [ ] 环形自动提交进度 → 可保留机械进度，避免闪烁  
- [ ] **例外：**「继续写」reply rise/fade → **仍播完整动画**（不跳过）

### 7.3 流式 × 浮现耦合

- 维护待绘字符缓冲：流式 `delta` 入队，动画按节奏出队。  
- 流暂停时动画等字；流赶上或 `done` 时按节奏消化积压，避免「卡住后一口气蹦完」的观感断层。  
- 不改为「等整段 done 再浮现」。

### 7.4 User Stories & Acceptance Criteria

**Story A** — 手机安全区与键盘  

- [ ] iOS Safari / Android Chrome 竖屏：顶栏与 dock 不被 Home Indicator 裁切  
- [ ] 文字模式聚焦键盘时，提交提示经 `visualViewport` 仍可见  
- [ ] 横屏：关键控件可点，不要求与竖屏同等打磨  

**Story B** — 减少动态  

- [ ] 渗墨无漂移/长 blur  
- [ ] 回答非缓慢逐字；可整段淡入或即现  
- [ ] 「继续写」仍有完整上升淡出（例外）  

**Story C** — 笔迹与 DPI  

- [ ] 有压感：可感知粗细变化，无异常尖刺  
- [ ] 无压感：固定舒适线宽  
- [ ] 高 DPR 设备上墨迹/回复不无故发虚（相对修复前）  

**Story D** — 双击提交  

- [ ] 双击空白仍可提交  
- [ ] 书写过程中的抬笔抖动不触发误提交  

### 7.5 Non-Goals

- 真笔迹笔顺回放  
- 新功能（语气、搜索、配额等归其它 PRD）  
- 性能微基准 CI（以手工设备清单为准）  
- 暗黑模式 / 宣纸主题  
- 设定内「动画：完整/减弱」开关  
- 「手感永久冻结」——允许后续微调；**新动画种类**仍应克制或另立说明  

### 7.6 Technology

- `src/lib/ink-motion.ts`、`src/lib/strokes.ts`  
- `src/components/InkPage.tsx`（浮现队列、续写动效、`visualViewport`）  
- `src/app/globals.css`（safe-area、dock、reduced-motion）  
- 设备手工矩阵：iPhone Safari、Android Chrome、桌面 Chrome（竖屏为主）

### 7.7 Assumptions

- 「手感」成功标准主观，故用**有界清单 + 设备走查**代替无休止打磨。  
- 流式与动画耦合优先于新视觉特效。  
- 续写动效在 reduced 下保留，是产品明确例外，不是遗漏。
