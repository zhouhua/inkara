# PRD：书写与浮现手感（Ink Feel）

**产品：** 墨语 · inkara  
**文档编号：** PRD-04  
**日期：** 2026-09-24  
**状态：** Draft  
**设计原则对齐：** `.impeccable.md`（动效如电子墨水刷新；缓慢、线性、低闪烁）

---

## 1. Summary

墨语的差异化在「纸与墨」的身体感：笔迹、渗入、逐字浮现、底栏按需出现。当前体验已可用，但仍有抖动、节奏不稳、移动端安全区与键盘顶起、减弱动效路径不完整等问题。本 PRD 定义一轮**纯体验打磨**，不新增业务功能入口。

## 3. Background

### 现状

- 书写：Canvas + 压感线宽（`strokes`）  
- 渗墨：`fadeInkIntoPaper`（约 1.4s）  
- 回答：手写体逐字浮现（非骨架笔顺回放；CJK 骨架方案已证明不可用）  
- 底栏：回复完成后显示清页/导出（page tools dock）  
- 已有 `prefersReducedMotion` 快捷路径，但各动画覆盖是否完整需审计

### 为什么现在做

功能面已够「能问能答」；手感决定品牌是否成立。适合在大功能之间插入一个专注质量的迭代。

---

## 4. Objective

**目标：** 在主流手机与桌面浏览器上，书写→提交→浮现的整段节奏稳定、不眩、不挡字，并完整尊重减少动态偏好。

### Key Results

| KR | 指标 | 目标 |
|----|------|------|
| KR1 | 减少动态全路径 | 审计清单 100% 覆盖（见 §7.2） |
| KR2 | 移动端 safe-area | 顶栏/底栏不被 Home Indicator 裁切 |
| KR3 | 文字模式键盘 | 聚焦时提交提示仍可见或可滚动见到 |
| KR4 | 浮现可读性 | 长回复（上限内）不出现严重掉帧；目标中端机 30fps+ 观感可接受 |
| KR5 | 无新功能入口 | 顶栏/设定不增加与手感无关的开关（允许「动画：完整/减弱」仅当系统偏好不足时——MVP 不做额外开关） |

## 7. Solution

### 7.1 打磨范围（有界）

本 PRD **只做**下列类别。每项必须可验收，禁止无上限「再调一调」。

| 类别 | MVP 包含 | 明确不做 |
|------|----------|----------|
| A. 笔迹 | 指针事件防误触双击提交的回归；线宽压感曲线轻微校准 | 模拟真实笔刷笔毛、倾斜角高级模型 |
| B. 渗墨 | 时长/位移在减弱动效下为 0；正常模式避免 blur 过重导致糊 | 粒子消散、水波纹 |
| C. 浮现 | 逐字节奏与流式到达的耦合检查（少「卡住再蹦字」）；减弱动效下可整段淡入或直接出示 | CJK 笔顺骨架回放、矢量描边动画 |
| D. 布局 | safe-area、dock 与键盘、横屏基本可用 | 新纸张材质引擎、暗色主题 |
| E. 控件显隐 | 底栏工具显隐过渡与 reduced-motion 一致 | 新的工具按钮 |

### 7.2 减少动态审计清单

以下路径在 `prefers-reduced-motion: reduce` 下必须无长位移/blur 动画：

- [ ] `fadeInkIntoPaper`  
- [ ] 回答逐字浮现（改为即时或短淡入）  
- [ ] `.submit-dock-tools` 显隐  
- [ ] 面板开闭若有 transform/opacity，改为即时或 ≤100ms opacity  
- [ ] 环形自动提交进度（若存在动画）可保留机械进度，但避免闪烁

### 7.3 User Stories & Acceptance Criteria

**Story A**  
As a 手机用户, I want 底栏提示和清页/导出不被系统条挡住, so that 我能点到。

- [ ] iOS Safari / Android Chrome 竖屏目视通过  
- [ ] `env(safe-area-inset-*)` 已正确作用在顶栏与 dock

**Story B**  
As a 开启减少动态的用户, I want 提交后不要渗墨漂移, so that 不晕。

- [ ] 系统开关打开时，渗墨立即清笔迹进入思考态  
- [ ] 回答不以缓慢逐字「跳」完（可接受快速显现）

**Story C**  
As a 书写用户, I want 线宽随压力变化自然, so that 像在纸上写。

- [ ] 有压感设备：可感知粗细变化  
- [ ] 无压感：固定舒适线宽，无异常尖刺

### 7.4 Non-Goals

- 真笔迹笔顺回放（已验证 CJK 不可用）  
- 新功能（语气、搜索、配额文案等归其它 PRD）  
- 性能微基准 CI（本仓库无 UI 自动化基建；以手工设备清单为准）  
- 暗黑模式 / 宣纸主题

### 7.5 Technology

- `src/lib/ink-motion.ts`、`src/lib/strokes.ts`  
- `src/components/InkPage.tsx` 动画调用处  
- `src/app/globals.css`（safe-area、dock、reduced-motion media）  
- 设备手工矩阵：至少 iPhone Safari、Android Chrome、桌面 Chrome/Safari 各一

### 7.6 Assumptions

- 「手感」成功标准是主观的，故必须用**有界清单 + 设备走查**代替无休止打磨。  
- 流式与动画耦合问题优先于新视觉特效。
