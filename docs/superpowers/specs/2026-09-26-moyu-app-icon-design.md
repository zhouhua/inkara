# 墨语 App 图标

日期：2026-09-26  
状态：已确认（落地改为直接使用「流畅 1」PNG，不再手绘 SVG）

## 问题

现有 PWA / favicon（`public/icons/icon-192.svg`、`icon-512.svg`）是「纸页 + 三道淡墨笔迹」。品牌讨论后决定改为**钢笔尖 + 压感笔迹**，以更贴合「在纸上书写」的产品动作，并提升主屏幕辨识度。

## 目标

- 产出一套可用于主屏幕 / PWA / favicon 的 App 图标
- 视觉气质对齐已确认参考图「流畅 1」
- 以 SVG 矢量交付，小尺寸（约 32–64px）仍可辨认笔尖与笔迹

## 非目标

- 不做横排字标 / 完整 lockup（「墨语」+ `inkara` 文字标识）
- 不引入渐变、金属高光、霓虹、3D 拟物
- 不直接用位图 PNG 作为唯一图标源（可保留参考图，运行时图标为 SVG）
- 不在本轮改动应用内 UI 插画或帮助页配图（除非引用同一图标文件）

## 已确认决策

| 项 | 选择 |
|----|------|
| 用途 | App 图标（PWA / 主屏幕 / favicon） |
| 主图形 | 钢笔尖 + 压感曲线（非墨滴） |
| 底板 | 浅色纸面 `#faf9f6` |
| 构图 | 竖向笔尖居上，流畅 S 形压感笔迹自尖端延出 |
| 定稿气质参考 | 「流畅 1」——见同目录 `2026-09-26-moyu-app-icon-reference.png` |
| 落地方式 | 按参考手工收成干净 SVG（几何笔尖 + 平滑贝塞尔笔迹） |

## 视觉规范

### 构图

- 画布方形；圆角约与现有图标一致（512 画布约 `rx=96`，192 等比缩放）
- 钢笔尖垂直居中、偏上；结构包含：笔领、肩翼、笔舌切面、中缝、气孔、尖端微开
- 自尖端起一条连续压感笔迹：少量三次贝塞尔构成外缘/内缘丝带，一笔写完
- 压感：触纸有存在感 → 腹部明显加粗 → 连续收成单尖（无分叉、无折线拼接）
- 笔迹须流畅（无锯齿感折点、无鼓包收笔）

### 色板

| 角色 | 色值 | 说明 |
|------|------|------|
| 纸面 | `#faf9f6` | 底板 |
| 墨色 | `#1c2233` | 笔尖主体与笔迹 |
| 切面 | `#3a4258` | 笔尖肩翼 / 中脊扁平切面（非渐变） |
| 高光缝 | `#faf9f6` | 中缝、气孔 |

禁止：紫霓虹、厚重阴影、金属反射渐变。

### 风格约束

- 扁平矢量、哑光纸感，对齐产品「单纯、克制、电子墨水本」气质
- 无文字、无品牌英文、无装饰印章

## 替换与接线

替换现有两枚 SVG 后，核对以下引用仍指向同一路径（通常无需改代码）：

- `src/app/layout.tsx`：`metadata.icons` / `apple` → `/icons/icon-192.png`、`/icons/icon-512.png`
- `public/manifest.webmanifest`：`icons[]` → PNG
- `public/sw.js`：预缓存路径同步为 PNG（cache 版本递增）

落地说明：手绘 SVG 无法复现「流畅 1」观感，最终直接缩放参考位图为 `icon-192.png` / `icon-512.png`。

## 验收

- [ ] 192 / 512 SVG 在浅色与系统主屏幕预览下，笔尖与笔迹可辨
- [ ] 约 32–64px 缩略时仍能看出「笔 + 一笔弧」，不糊成一团
- [ ] 笔迹边缘平滑，无可见折线感
- [ ] 色板与现有纸面 UI（`#faf9f6` / 墨青）一致
- [ ] `layout` / `manifest` 图标路径加载正常；安装 PWA 后主屏幕为新图标

## 实现备注

- 笔迹优先用手调贝塞尔丝带（外缘/内缘对称节奏），避免密集折线模拟压感
- 笔尖可用 2 个扁平色阶表达结构，保持矢量可编辑
- 实现前可用参考 PNG 对照比例；最终以 SVG 为准入库
