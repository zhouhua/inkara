## Locked implementation details

### Pressure curve (`strokes.ts`)

```ts
/** Normalize pointer pressure: treat 0 / missing as “no sensor” → mid comfort. */
export function normalizePressure(raw: number): number {
  if (!(raw > 0) || raw === 0.5 /* common browser default when unknown */) {
    // Keep 0.5 as “unknown” fixed comfort — do not amplify
    return 0.5;
  }
  // Dead-zone + soft ceiling to avoid hairline spikes / broom ends
  const t = Math.min(1, Math.max(0, (raw - 0.08) / 0.84));
  return 0.28 + t * 0.72; // maps into ~0.28–1.0
}

export function strokeWidth(pressure: number, dpr: number, erase: boolean) {
  const p = normalizePressure(pressure);
  if (erase) return (18 + p * 22) * dpr;
  // Fixed comfort when unknown (0.5 after normalize of default): ~3.4–4.2 css px
  const base = 2.4;
  const span = 3.2; // max extra at full press
  return (base + p * span) * dpr;
}
```

Update `pointerToPoint` to store **raw** `e.pressure` (or 0 if missing); apply `normalizePressure` only inside `strokeWidth`. Export `strokeWidth` for sanity (currently private — export it).

**Do not** add speed-based width.

### Stream × reveal coupling

**Today:** `onDelta` only concatenates; `animateAnswer(finalReply)` runs after stream ends → perceived stall then cascade.

**Locked:**

1. `let liveReply = ""`, `let streamDone = false`, `let revealStarted = false`.
2. `onDelta`: `liveReply += text`; if `!revealStarted && liveReply.length > 0`, set `revealStarted = true`, `setPhaseBoth("answering")`, start `void pumpReveal(...)` (do not await inside onDelta).
3. `pumpReveal` loops until `streamDone && painted >= layout(liveReply).length`:
   - If no new chars yet and `!streamDone`, `await sleep(32)` and continue.
   - Else paint next char with existing 3-step `drawInkChar` + `charRevealDelay` (non-reduced).
   - Re-layout from full `liveReply` each char (same as today’s `layoutOnce`) so wrapping stays correct as text grows.
4. After `askPageStream` resolves: set `liveReply = result.reply || liveReply` (prefer server final), then `streamDone = true`; `await revealPromise` (if started).
5. If final intent is **recall**: cancel reveal; `clearReplyLayer()`; run existing recall path (brief partial ink is acceptable).
6. If reveal never started (empty reply): keep current empty handling.
7. **Do not** call `clearReplyLayer()` immediately before awaiting the pump on the answer path once reveal has started (today’s `clearReplyLayer()` just above `animateAnswer` must go for the live path).

Reduced path during stream: **lock: wait until streamDone then ≤180ms fade** via `fadeInReplyBlock({ paint, durationMs: 180, signal })` (Task 2 API).

2. **Two-frame enable** so transition actually runs under reduce:

```ts
  requestAnimationFrame(() => {
    setRising(true);               // class is-rising — now transitions apply
  });

// on transitionend / 500ms timeout: setRising(false); setBackground(true); setContinueMotion(false); ...
```

3. CSS:

```css
@media (prefers-reduced-motion: reduce) {
  .reply-stage {
    transition: none;
  }
  /* Exception: Continue rise/fade still animates */
```

### visualViewport → dock

```ts
// InkPage
const [vvOffset, setVvOffset] = useState(0);
useEffect(() => {
  const vv = window.visualViewport;
  if (!vv) return;
  const sync = () => {
    // keyboard overlap ≈ layout viewport bottom - visual viewport bottom

  vv.addEventListener("scroll", sync);
  sync();
  return () => { ... };
}, []);
```

**Files:**

- [ ] **Step 1: Tune** `fadeInkIntoPaper` duration 1200, blur `0.25 + e * 1.2`.

```ts
export async function fadeInReplyBlock(
  opts: {
    durationMs?: number;
    signal?: { cancelled: boolean };
    paint: (alpha: number) => void;
  }
): Promise<void> {
  const duration = opts.durationMs ?? 180;
  const start = performance.now();
  await new Promise<void>((resolve) => {
    const tick = (now: number) => {
      if (opts.signal?.cancelled) return resolve();
      const p = Math.min(1, (now - start) / duration);
      opts.paint(p);
      if (p < 1) requestAnimationFrame(tick);
      else resolve();
    };
    requestAnimationFrame(tick);
  });
}
```
